Tours and Travels – Telangana Tourism Website

A degree project website developed to present Telangana's tourist destinations, heritage, arts and crafts, waterfalls, tour packages, booking options, gallery content, guides, contact information, and visitor feedback.

Project Overview

The Tours and Travels project is a front-end web prototype focused on making Telangana tourism information easier to explore through a structured website.

The project provides:

A welcome and home page

User login page

District-wise tourist destinations

Information about historic sites

Telangana arts and crafts

Waterfalls and natural attractions

Tour packages

Train and bus booking forms

Photo and video gallery

Guide information/form

Contact form

Feedback form

Navigation between the different sections of the website

The project report describes the initial scope as a front-end prototype using HTML/CSS, with room for future expansion and more advanced functionality.

Key Features

🏠 Home

Introduces the Telangana Tours and Travels website and provides navigation to the main sections.

🔐 Login

Provides a login form where users can enter their username and password before accessing the website.

🏛️ Heritage and Culture

The About section presents:

Historic sites

Arts and crafts

Waterfalls

🎒 Tour Packages

Displays travel package information, including destinations and estimated travel costs.

🚌🚆 Booking

Includes booking forms for travel by:

Bus

Train

Users can enter travel details such as the number of travelers and journey timing.

🖼️ Gallery

Contains tourism-related photos and videos organized around Telangana destinations.

🧑‍💼 Guide

Provides a section for guide-related information and contact details.

📞 Contact

Provides a contact form for visitor enquiries and communication.

💬 Feedback

Provides a feedback section where visitors can share their travel experience, suggestions, and ratings.

How to Run

This is a front-end web project, so no server-side installation is required for the basic prototype.

Using Visual Studio Code

Clone or download this repository.

Open the project folder in Visual Studio Code.

Open the main HTML page.

Right-click the HTML file.

Select Open with Live Server if the Live Server extension is installed.

The website will open in your browser.

You can also open the HTML file directly in a modern web browser.
